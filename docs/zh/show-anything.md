# 展示任何（Show Anything）

**分类：** `Capricorncd`

在节点上显示任意连接值（与 Easy-Use **展示任何** 相同思路），并提供 **格式化 JSON** 开关。

与 [Format JSON](format-json.md) 不同：

- 接受 **任意** 类型（`*`），不限于字符串
- 将上次显示的文本写入工作流 `widgets_values`
- **无输入时不会清空**显示——刷新 / 重启并恢复工作流后仍可看到上次内容

---

## 输入参数

| 名称 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `anything` | `*` | — | 可选。要展示并原样传出的任意值 |
| `format_json` | BOOLEAN | true | 开启时尝试将 JSON 字符串 / 可序列化对象缩进显示 |

## 输出参数

| 名称 | 类型 | 说明 |
|------|------|------|
| `output` | `*` | 原样传出输入值 |

---

## 持久化

每次成功更新显示时写入：

```text
widgets_values = [format_json, ...display_texts]
```

前端在 `onConfigure` 时恢复文本控件，因此浏览器刷新或重启 ComfyUI 并加载工作流后，仍会显示上次内容。若环境不会自动保存，请在运行后手动保存工作流。
